Zong Monthly Package Kaise Lagayein?

  1. Apne Zong number se upar diya gaya code dial karein, masalan Monthly Pro ke liye *7088#.
  2. Screen par aane wali hidayat par confirm dabayein.
  3. Confirmation SMS aane par package active ho jayega.
  4. My Zong app se bhi koi bhi package asaani se lagaya ja sakta hai.

Balance aur Package Status Kaise Check Karein?

My Zong app mein aap apna bacha hua balance, minutes aur data dekh sakte hain. Ya *102# dial kar ke bhi bacha hua balance aur resources check kiye ja sakte hain.

Kaunsa Package Aapke Liye Behtar Hai?

  • Kam kharch, sirf calls: Mahana Voice Plus (Rs 450) — zyada minutes, koi data nahi.
  • Social media zyada: Monthly Social Plus (Rs 700) — 20 GB social data ke sath calls bhi.
  • Mutawazan bundle: Monthly Super Card (Rs 1,700) — unlimited Zong calls aur 10 GB data.
  • Sab se zyada data: Monthly Pro (Rs 2,300) — 50 GB ke sath bhari minutes aur SMS.
